The decrease in order implies a finite $Δ_{trs}\kSent$. We should stress at this point that we are talking about first order transitions here. The reason for this terminology is that the discontinuity is in a function like $\kSent$, that is a first order derivative of $\kG$ (or $A$):

$$ \left(\frac{\partial\kGbar}{\partial \kT}\right)_{\kP}=-\kSbar $$

Second order derivatives (e.g. the heat capacity) will display a singularity (+∞) at the transition point.

Kinds of phase transition

Every phase transition will have a change in entropy associated with it. The different types of phase transitions that can occur are:

Table
$l \rightarrow g$Vaporization / boiling
