# Physical Chemistry (LibreTexts)

The OmniStax edition of *Physical Chemistry* (LibreTexts), the Physical Chemistry Textbook Map on chem.libretexts.org, by Delmar Larsen et al. The app that reads it, the shared tools and the rules for building a book are in [OmniStax/OmniStax](https://github.com/OmniStax/OmniStax); clone this repository into that one's `omnistax-content/` folder (`npm run books` there does it).

## Status

Full-book exploration (root rule 1 and 18). Nothing is built yet: `exploration.md`, a draft `RULES.md` and `COLOR.md`, the tools that mirror and convert the source, and Chapter 1's converted pages, `exploration.md` and proposed `config.md`.
